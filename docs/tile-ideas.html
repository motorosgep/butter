A · Hero reading + sparkline (sensors and climate)

B · State colour: what's on, lights up

Tiles stay neutral when a device is idle and fill with a colour that means something when it's active: butter yellow for a light that's on, blue for cooling, orange for heating, green for a running fan. You find the lamp that was left on across the room without reading a single title. This is the single biggest scanning win and needs no user configuration.

C · Per-device icon and colour, synced through the hub

Your option A, done properly. Each device gets an icon from a large library and an accent colour from a palette; both are stored as a tag on the hub like rooms are, so they follow you to every phone. The colour tints the badge and, faintly, the tile; the icon replaces the generic category one. Picked once from the device page.

Problems: text needs a dark gradient to stay readable, so every photo ends up half black; photos can't be synced through the hub (tags hold short strings), so they're per phone; mixed photo and plain tiles look patchy; and state colour (B) no longer has anywhere to go. It photographs well in a screenshot and scans worse in daily use. I'd keep it out, or offer it only for the few "featured" tiles in E.

E · Featured tiles: pin what matters, make it bigger

Your "highlight the important tiles". Long-press a tile to pin it; pinned tiles become wide, sit in a Favourites section at the top of Home, and carry the extra detail from A. The rest of the house stays compact below. The pinned set is stored on the hub too, so it's the same on every phone.

Recommendation

Build B + A + E as one change, in that order of value: state colour costs nothing and fixes scanning for every user; hero readings fix the sensor tiles; favourites give you control over what's big. Then C (icon and colour per device, synced via hub tags) as the personalisation layer. Skip D or limit it to featured tiles. All of it is JavaScript, so it ships over the air.
